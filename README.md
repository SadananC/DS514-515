## 1. บทนำ (Introduction)
ปัจจุบัน ภาวะผิดปกติเกี่ยวกับการนอนหลับ (Sleep Disorder) เช่น โรคนอนไม่หลับ (Insomnia) และภาวะหยุดหายใจขณะหลับ (Sleep Apnea) กำลังเป็นปัญหาทางสุขภาพที่สำคัญและส่งผลกระทบโดยตรงต่อคุณภาพชีวิต ประสิทธิภาพการทำงาน รวมถึงเพิ่มความเสี่ยงต่อการเกิดโรคเรื้อรังในระยะยาว ซึ่งสาเหตุของภาวะดังกล่าวมักเกิดจากปัจจัยเสี่ยงหลายด้านที่สะสมร่วมกัน ทั้งในมิติของพฤติกรรมการใช้ชีวิตประจำวันและสภาวะทางสรีรวิทยา ได้แก่ ระยะเวลาการใช้หน้าจอก่อนนอน (Screen Time Before Bed) ที่รบกวนวงจรการหลับตามธรรมชาติ พฤติกรรมการดื่มกาแฟและแอลกอฮอล์ การรับประทานมื้ออาหารก่อนนอน (Meals Before Bed) ตลอดจนตัวชี้วัดทางสุขภาพอย่าง ระดับความดันโลหิต (Blood Pressure) ระดับความเครียด และช่วงอายุ

ดังนั้น การศึกษานี้จึงได้นำชุดข้อมูลพฤติกรรมการนอนและปัจจัยทางสุขภาพของกลุ่มประชากรตัวอย่างจำนวน 374 รายการ มาวิเคราะห์ความสัมพันธ์เชิงลึกระหว่างปัจจัยด้านพฤติกรรมและสุขภาพดังกล่าว เพื่อพัฒนาเป็นแบบจำลอง Machine Learning ประเภทการจำแนกประเภท (Supervised Classification) สำหรับทำนายความเสี่ยงในการเกิดภาวะผิดปกติเกี่ยวกับการนอนหลับ (Sleep Disorder) โดยมุ่งหวังให้แบบจำลองนี้เป็นเครื่องมือคัดกรองความเสี่ยงเบื้องต้น (Preliminary Screening) และสนับสนุนการวางแผนปรับเปลี่ยนพฤติกรรมการใช้ชีวิตของกลุ่มเป้าหมายได้อย่างแม่นยำและตรงจุด

## 2. วัตถุประสงค์ (Objectives)
เพื่อสร้างแบบจำลองในการทำนาย/จัดกลุ่ม **[ระบุสิ่งที่ต้องการทำนาย]** โดยสอดคล้องกับ SMART Objectives ที่ตั้งไว้ก่อนหน้า:
* **Specific (เจาะจง):** สร้างแบบจำลอง Machine Learning เพื่อทำนาย...
* **Measurable (วัดผลได้):** โมเดลมีประสิทธิภาพวัดจากค่า Accuracy / Recall / F1-Score ไม่ต่ำกว่า **[ระบุตัวเลข]%**
* **Achievable (ทำได้จริง):** พัฒนาโดยใช้ชุดข้อมูลและอัลกอริทึมมาตรฐานทางด้าน Data Science
* **Relevant (สอดคล้อง):** ช่วยสนับสนุนการตัดสินใจในด้าน...
* **Time-bound (มีกรอบเวลา):** ดำเนินการแล้วเสร็จภายในระยะเวลาที่กำหนดของรายวิชา

## 4. Data Dictionary

### ตัวแปรเป้าหมาย (Target Variable)
* `ชื่อคอลัมน์เป้าหมาย` (ประเภทข้อมูล): คำอธิบายความหมาย (เช่น `1` = เกิดเหตุการณ์, `0` = ไม่เกิดเหตุการณ์)

### ตัวแปรอิสระ (Features)
| ชื่อตัวแปร (Feature) | ประเภทข้อมูล (Data Type) | คำอธิบาย (Description) |
| :--- | :--- | :--- |
| `Feature_1` | Integer / Float | คำอธิบายตัวแปรที่ 1 |
| `Feature_2` | Categorical | คำอธิบายตัวแปรที่ 2 (เช่น M = ชาย, F = หญิง) |
| `Feature_3` | Integer | คำอธิบายตัวแปรที่ 3 |

## 5. การวิเคราะห์ข้อมูลเชิงสำรวจ (EDA)
สรุปสิ่งที่ค้นพบจากการสำรวจข้อมูลเบื้องต้น:
* **การกระจายตัวของ Target (Class Balance):** ระบุสัดส่วนของข้อมูลเป้าหมาย (เช่น กลุ่ม 1 มี 55% และกลุ่ม 0 มี 45%)
* **ความสัมพันธ์ของตัวแปร (Correlation):** ระบุตัวแปรที่มีความสัมพันธ์กับตัวแปรเป้าหมายอย่างมีนัยสำคัญ
* **ความผิดปกติของข้อมูล:** ระบุค่าว่าง (Missing Values) หรือค่าผิดปกติ (Outliers) ที่ตรวจพบ
